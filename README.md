# Academic Pass/Fail Evaluator

A web-based application to evaluate **Pass/Fail status** of students based on university-defined academic rules.  
This project is designed for **college evaluation systems** and helps students quickly verify their results.

---

## 🚀 Features

- Theory course pass/fail evaluation  
- Practical course pass/fail evaluation  
- Customizable weightage (Attendance, CA, MTE, ETE, Practical)  
- Dark / Light mode toggle  
- Instant result calculation  
- Clear failure reason display  
- Responsive and modern UI (Tailwind CSS)

---

## 📊 Passing Criteria

### Theory Courses
- Minimum **30% in ETE**  
  **OR**
- Minimum **30% in combined (MTE + ETE)**
- **Overall total ≥ 40%**
- If any condition fails → **Fail**

### Practical Courses
- Minimum **30% in Practical exam**
- **Overall total ≥ 40%**
- If any condition fails → **Fail**
